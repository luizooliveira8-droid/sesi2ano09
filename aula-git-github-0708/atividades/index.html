Atividade 1 – Olá, Mundo! #include int main() { printf("Olá, Mundo!\n"); printf("Bem-vindo à programação em C.\n"); return 0; } Explicação: #include permite usar funções de entrada e saída, como printf(). A função printf() exibe os textos na tela. \n pula para a próxima linha e return 0 indica que o programa terminou corretamente. Atividade 2 – Apresentação #include int main() { char nome[50]; int idade; printf("Digite seu nome: "); scanf("%49s", nome); printf("Digite sua idade: "); scanf("%d", &idade); printf("Olá, %s! Você tem %d anos.\n", nome, idade); return 0; } Explicação: char nome[50] cria uma variável para armazenar o nome. int idade armazena a idade como número inteiro. scanf() recebe os dados digitados pelo usuário. %s é usado para texto e %d para números inteiros. Atividade 3 – Soma #include int main() { int num1, num2, soma; printf("Digite o primeiro número: "); scanf("%d", &num1); printf("Digite o segundo número: "); scanf("%d", &num2); soma = num1 + num2; printf("A soma é: %d\n", soma); return 0; } Explicação: O programa cria três variáveis inteiras. Os dois números são digitados pelo usuário e armazenados em num1 e num2. Depois, o operador + soma os valores e guarda o resultado em soma. Atividade 4 – Quatro operações #include int main() { int num1, num2; printf("Digite o primeiro número: "); scanf("%d", &num1); printf("Digite o segundo número: "); scanf("%d", &num2); printf("Soma: %d\n", num1 + num2); printf("Subtração: %d\n", num1 - num2); printf("Multiplicação: %d\n", num1 * num2); if (num2 != 0) { printf("Divisão inteira: %d\n", num1 / num2); } else { printf("Não é possível dividir por zero.\n"); } return 0; } Explicação: O programa realiza quatro operações matemáticas: + soma, - subtração, * multiplicação e / divisão. Como as variáveis são int, a divisão é inteira. O if verifica se o segundo número é diferente de zero antes de dividir. Atividade 5 – Antecessor e sucessor #include int main() { int numero; printf("Digite um número inteiro: "); scanf("%d", &numero); printf("Antecessor: %d\n", numero - 1); printf("Sucessor: %d\n", numero + 1); return 0; } Explicação: O antecessor é encontrado diminuindo 1 do número. O sucessor é encontrado aumentando 1. Por exemplo, se o número for 10, o antecessor será 9 e o sucessor será 11. Atividade 6 – Média #include int main() { float nota1, nota2, media; printf("Digite a primeira nota: "); scanf("%f", ¬a1); printf("Digite a segunda nota: "); scanf("%f", ¬a2); media = (nota1 + nota2) / 2; printf("A média é: %.2f\n", media); return 0; } Explicação: As notas são armazenadas como float, pois podem possuir números decimais. A média é calculada somando as duas notas e dividindo o resultado por 2. %.2f mostra o resultado com duas casas decimais. Atividade 7 – Celsius para Fahrenheit #include int main() { float celsius, fahrenheit; printf("Digite a temperatura em Celsius: "); scanf("%f", &celsius); fahrenheit = (celsius * 9 / 5) + 32; printf("Temperatura em Fahrenheit: %.2f\n", fahrenheit); return 0; } Explicação: O programa recebe uma temperatura em Celsius e utiliza a fórmula F = (C * 9 / 5) + 32 para convertê-la para Fahrenheit. As variáveis são float para permitir temperaturas com casas decimais. Atividade 8 – Área do retângulo #include int main() { float base, altura, area; printf("Digite a base do retângulo: "); scanf("%f", &base); printf("Digite a altura do retângulo: "); scanf("%f", &altura); area = base * altura; printf("A área do retângulo é: %.2f\n", area); return 0; } Explicação: Para calcular a área de um retângulo, usamos a fórmula área = base × altura. O programa recebe a base e a altura e multiplica os dois valores. Atividade 9 – Salário #include int main() { float valorHora, salario; int horasTrabalhadas; printf("Digite o valor da hora trabalhada: "); scanf("%f", &valorHora); printf("Digite a quantidade de horas trabalhadas: "); scanf("%d", &horasTrabalhadas); salario = valorHora * horasTrabalhadas; printf("O salário é: R$ %.2f\n", salario); return 0; } Explicação: O programa recebe o valor que a pessoa ganha por hora e a quantidade de horas trabalhadas. Depois, multiplica os dois valores para calcular o salário. Atividade 10 – Calculadora #include int main() { int num1, num2; printf("Digite o primeiro número: "); scanf("%d", &num1); printf("Digite o segundo número: "); scanf("%d", &num2); printf("Soma: %d\n", num1 + num2); printf("Subtração: %d\n", num1 - num2); printf("Multiplicação: %d\n", num1 * num2); if (num2 != 0) { printf("Divisão: %d\n", num1 / num2); printf("Resto da divisão: %d\n", num1 % num2); } else { printf("Não é possível dividir por zero.\n"); } return 0; } Explicação: Além das quatro operações, esse programa utiliza %, que calcula o resto da divisão inteira. Por exemplo, 10 % 3 resulta em 1, porque 10 dividido por 3 deixa resto 1. Desafio Extra – Ficha do aluno #include int main() { char nome[50]; int idade; float nota1, nota2, media; printf("Digite o nome do aluno: "); scanf("%49s", nome); printf("Digite a idade: "); scanf("%d", &idade); printf("Digite a nota 1: "); scanf("%f", ¬a1); printf("Digite a nota 2: "); scanf("%f", ¬a2); media = (nota1 + nota2) / 2; printf("\n===== FICHA DO ALUNO =====\n"); printf("Nome: %s\n", nome); printf("Idade: %d anos\n", idade); printf("Nota 1: %.2f\n", nota1); printf("Nota 2: %.2f\n", nota2); printf("Média final: %.2f\n", media); return 0; } Explicação: O programa reúne tudo em uma única atividade. Ele recebe o nome, idade e duas notas do aluno. Depois calcula a média com (nota1 + nota2) / 2 e apresenta todas as informações organizadas como uma ficha.
